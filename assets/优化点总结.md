- # 内容优化方案

## 模型选择与参数优化

模型组合策略

对于技术性、结构化内容，优先选择DeepSeek的ERNIE X1.1或ERNIE 4.5模型，因其在事实性、指令遵循和多模态能力上有显著优势。

对于创意性、口语化内容，则更适合使用豆包的"Seedream 4.0"或"Seedream 4.5"模型，因其在语言自然度和情感表达上更为出色。

参数配置优化

• DeepSeek模型：温度值(temperature)控制在0.3-0.7之间

• 豆包模型：温度值建议设置为0.6-0.8

• 根据内容长度需求合理设置max_tokens参数

```
# 模型选择与参数配置示例
from coze决策 import IntentRecognizer, TaskPlanner

class 微信公众号内容类型识别(IntentRecognizer):
    def recognize(self, input_data):
        if "技术分析" in input_data["text"]:
            return "技术型内容"
        elif "故事叙述" in input_data["text"]:
            return "创意型内容"
        else:
            return "通用型内容"

class 微信公众号内容生成计划(TaskPlanner):
    def plan(self, intent):
        if intent == "技术型内容":
            return [
                {"action": "调用DeepSeek模型", "params": {"temperature": 0.5, "max_tokens": 500}}
            ]
        elif intent == "创意型内容":
            return [
                {"action": "调用豆包模型", "params": {"temperature": 0.7, "max_tokens": 800}}
            ]
        else:
            return [
                {"action": "调用默认模型", "params": {"temperature": 0.6, "max_tokens": 600}}
            ]
                
```

## 功能节点能力增强

搜索功能优化

结合模型的NLP分析能力和外部搜索工具，构建更强大的语义理解系统。通过Coze的插件机制集成Elasticsearch或壹伴搜索API，实现多条件、高相关性的搜索结果获取。

排版功能增强

建议优先考虑壹伴助手的API集成，根据2025年测评数据，壹伴助手在AI排版效率方面表现突出，其"AI一键排版"功能能在30秒内自动完成字体匹配、段落间距、图片排版等操作。

```
# 外部搜索插件实现
from runtime import Args
from request import post
from parse import parse_json

class 外部搜索插件:
    def handler(self, args: Args):
        # 获取模型传递的关键词
        keywords = args.input keywords
        # 构建Elasticsearch查询
        query = {
            "query": {
                "multi_match": {
                    "query": keywords,
                    "fields": ["title^3", "content"]
                }
            },
            "size": 10
        }
        # 调用Elasticsearch API
        response = post("https://elasticsearch.example.com/_search", json=query)
        # 解析返回结果
        results = parse_json(response.text)
        # 提取关键信息
        relevant_info = []
        for hit in results["hits"]["hits"]:
            relevant_info.append({
                "title": hit["_source"]["title"],
                "content": hit["_source"]["content"],
                "score": hit["score"]
            })
        # 返回结构化数据
        return {"search_results": relevant_info}
                
```

## 图片生成与处理流程优化

图片生成策略

对于豆包模型，其图片生成API明确支持`watermark`参数设置为`false`生成无水印图片。

对于DeepSeek模型，建议采用"DeepSeek生成提示词+外部工具生成图片"的组合方案。

图片处理流程

- 图片生成：确保无水印且符合尺寸要求
- 图片优化：使用TinyPNG等工具压缩至500KB以内
- 图片与文字排版：自动调整图片位置和大小
- 图片风格统一：根据品牌调性添加统一滤镜

```
# 豆包图片生成节点实现
from coze.插件 import 豆包图片生成

class 豆包图片生成节点:
    def handler(self, args: Args):
        # 获取生成提示词
        prompt = args.input prompt
        # 调用豆包图片API
        image_url = 豆包图片生成(
            prompt=prompt,
            model="doubao-seedream-4-5-251128",
            size="1080x720",
            output_format="png_no_watermark",
            watermark=False
        )
        # 返回图片URL
        return {"image_url": image_url}
                
```

## 符合规范的排版算法设计

排版规范要求

• 全角中文字符与半角英文字符间必须加半角空格

• 段落行高设置为1.5-1.8倍（正文13px时，行高20-24px最佳）

• 正文首行缩进2字符

• 图片宽度不超过1080px，封面图尺寸为900×383

技术实现方案

采用"Markdown转HTML+CSS模板"的排版方案。使用DeepSeek或豆包生成符合Markdown语法的内容，然后转换为微信公众号兼容的HTML格式，并注入CSS样式。

```
# Markdown转HTML并注入CSS样式
from runtime import Args
from markdown import markdown
from request import post

class Markdown转HTML节点:
    def handler(self, args: Args):
        # 获取Markdown内容
        md_content = args.input md
        # 转换为HTML
        html_content = markdown(md_content)
        # 注入CSS样式
        final_html = f"""
        
            body {{ font-family: 微信正黑体; font-size: 15px; line-height: 1.75; margin: 0; padding: 0; }}
            h1 {{ font-size: 16px; margin-bottom: 20px; }}
            h2 {{ font-size: 14px; margin-bottom: 15px; }}
            p {{ margin: 10px 0; text-indent: 2em; }}
            img {{ max-width: 100%; height: auto; margin: 10px 0; }}
        
        {html_content}
        """
        # 返回最终HTML
        return {"html_content": final_html}
                
```

## 内容审核与反馈机制

多层级审核机制

**自动化审核**：利用DeepSeek的text/classify接口进行文本分类，使用网易易盾API进行敏感内容检测。

**人工复核**：对高风险内容强制人工审核，建立多级审核流程。

**用户反馈**：在文章末尾嵌入反馈表单，收集用户评价。

数据关联分析

记录每次生成内容的元数据（模型版本、提示词、参数配置），便于分析问题根源。根据分析结果优化提示词模板或调整参数配置。

```
# 内容审核节点实现
from coze.插件 import 网易易盾

class 内容审核节点:
    def handler(self, args: Args):
        # 获取生成内容
        text = args.input text
        image_url = args.input image_url
        # 调用网易易盾API进行审核
        result = 网易易盾(
            text鉴权(text, api_key="YOUR_API_KEY"),

        )
        # 检测结果处理
```
